# Western Technical College - Web Development Coursework

This repository hosts the lessons, coursework, and coding assets for students at Western Technical College.

Live Website: [http://borresonh.westernstudent.com/](borresonh.westernstudent.com/)

## Tech Stack
* HTML5
* CSS3
* JavaScript (ES6+)

## Project Structure
* `index.html` - Homepage and course navigation portal.
* `lessons/` - Individual course modules and lab folders.
* `assets/` - Global stylesheets, images, and shared JavaScript files.

## Local Setup
1. Clone the repository to your computer.
2. Open the project folder in your text editor (like VS Code).
3. Run a local development server (like Live Server) to view `index.html`.

## Deployment
Deploy to main and then update files in cPanel.

## Guidelines
* Write clean, semantic, and well-commented code.
* Open a pull request using the project template for any changes.
